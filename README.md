# 成分ノート・確認用試作

hairuとは独立したサイト。名称は仮称。公開範囲は所有者のみ。

機能：10悩み、37分岐、必要な追加1問、成分名・別名検索、根拠と注意、商品区分、購入リンクの案内。

データは医療監修前の編集用シードです。公開済みの推奨データではなく、試作内で確認するために表示しています。楽天の通常購入リンクを3件登録。販売先は購入リンクだけを扱い、価格・在庫の取得や表示は行いません。回答はメモリ内のみで、アクセス解析は導入していません。

検証：JavaScript構文、87件の分岐・成分画面ケース、別名検索、レチノール除外、刺激時の保湿置換、医薬品除外、販売先の欠損状態を検証。WebMCPは模擬環境で正常入力・不正入力を確認。実ブラウザ／対応WebMCP環境の検証は実行環境の制約により未完了。

静的配信対象：dist/。設計の正本と初期CSVは上位のoutputsにあります。
